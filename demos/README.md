# Demos — Sistema de captación de clientes para fotógrafo/videógrafo (Beverly Hills)

Tres demos interactivas construidas para mostrarle a un fotógrafo/videógrafo de Beverly Hills
cómo la IA puede conseguirle clientes (marcas y agencias) y multiplicar su contenido.
Cada una es un solo archivo HTML autocontenido (sin dependencias externas), optimizado para
abrirse desde el navegador de Instagram en el celular.

## Las tres demos

| Demo | Archivo | Qué resuelve |
|------|---------|--------------|
| **LeadFlow** — Motor de email marketing con IA | `leadflow.html` | Atraer: leads verificados tipo Apollo, secuencias de 3 toques, generador de emails personalizados con IA, agente autónomo que clasifica respuestas y redacta contestaciones |
| **ClipEngine** — Estudio de contenido IA | `clipengine.html` | Demostrar valor: convierte una entrevista de calle en clips virales con hooks, captions por plataforma, calendario de publicación y versiones patrocinadas vendibles a marcas |
| **Media Kit Vivo** — Portal para marcas | `mediakit.html` | Cerrar: portafolio + generador de propuestas con IA (industria/objetivo/presupuesto → campaña con precios), calculadora de ROI y agenda de shoots |

Juntas cubren el embudo completo: **atraer → demostrar → cerrar**.

## Cómo se verían en producción

- **LeadFlow**: Apollo.io para leads, Instantly/Smartlead para envío con calentamiento de inbox,
  Claude para redactar y clasificar, calendario conectado para agendar.
- **ClipEngine**: Whisper para transcripción, Claude para detección de momentos y copywriting,
  corte/reencuadre 9:16 automático, publicación programada en TikTok/Reels/Shorts.
- **Media Kit Vivo**: portal en dominio propio; cada marca que llega por email o DM aterriza ahí,
  recibe propuesta generada con los precios reales y agenda directo.

Todos los datos de las demos son simulados.
